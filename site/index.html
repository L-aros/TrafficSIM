TrafficSIM

按 Wi-Fi 规则自动切换数据卡的 LSPosed 模块

围绕 SSID / BSSID 规则、后台常驻、权限自检与焦点通知调试构建。 当前版本仅保留 LSPosed 单链路切卡，不再提供 Root 兜底。

查看发布 快速开始 README
  • 支持规则优先级、离开 Wi-Fi 回切、无 Wi-Fi 目标卡与即时切换。
  • 内置权限说明、权限配置、自检页与日志导出。
  • 主要验证环境为小米 HyperOS，其他 ROM 仍需持续补样本。
01

规则驱动

按 SSID / BSSID 识别 Wi-Fi 环境，支持优先级、冷却时间与离开规则回切。

02

单链路切卡

通过 LSPosed 电话进程桥接执行默认数据卡切换，减少 Root 依赖与分叉逻辑。

03

可调试通知

保留焦点通知与切卡事件通知链路，便于验证大岛、小岛与普通通知展示状态。

04

权限与保活

应用内提供权限说明、权限配置与厂商设置跳转，降低后台受限导致的误判。

Quick Start

三步进入可用状态

1

安装与启用

安装与设备 ABI 匹配的 APK，在 LSPosed 中启用模块并勾选推荐电话作用域。

2

授予权限

授予定位、附近 Wi-Fi、电话状态和通知权限，并确认系统定位总开关已开启。

3

学习或创建规则

通过“学习 -> SIM1 / SIM2”快速生成规则，或手动指定 SSID、BSSID 与目标卡槽。

Workflow

围绕常驻模式做了更重的稳定性设计

Wi-Fi 快照

在连接切换与 captive portal 场景下缓存 SSID / BSSID，提高规则匹配稳定性。

广播补跑

收到 Wi-Fi 或网络变化后立即补跑规则评估，避免仅靠轮询导致的延迟。

通知反馈

切卡结果、焦点通知与自检结果分层展示，方便用户确认“命中规则”和“切卡成功”不是一回事。

Compatibility

兼容性说明与边界

当前重点验证

小米 HyperOS 环境优先，双卡设备与高通电话栈验证更完整。

其他 ROM

One UI、ColorOS、OriginOS 等系统可能因电话进程、保活策略或权限入口差异而出现兼容偏差。

作用域建议

推荐勾选 `com.android.phone`、`com.xiaomi.phone`、`com.qti.phone`、`com.qualcomm.qti.telephonyservice`、`com.android.services.telephony`、`com.android.telephony`；必要时再尝试 `android`。
